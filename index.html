How this works

Automatic public game feed

GitHub Actions retrieves available ESPN scoreboard information and publishes a static JSON file. The optional live-score module attempts direct ESPN updates while the app is open. If those requests are blocked, the saved game feed remains available.

Five-model engine

Calculates weighted scoring margins from values you enter. The experimental custom ratings are automatically computed from available prior completed games. SP+, FPI, FEI and Action remain unconnected. Missing inputs are never fabricated.

Odds and risk

Sportsbook prices and personnel checks must be verified manually. This is a research screen, not a calibrated betting recommendation. No gambling or account integrations.

Privacy

Wagers stay in your browser storage. This is not encrypted or synced. Never commit ledger exports, API keys or credentials to a public repository.
